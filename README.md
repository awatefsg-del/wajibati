# واجباتي — My Assignments

موقع ويب لإدارة الواجبات والمهام الدراسية، مبني بـ HTML/CSS/JS (بدون خادم)،
يعتمد على **localStorage** لتخزين البيانات، مع تسجيل دخول لكل مستخدم (بريد + كلمة مرور)،
وعزل كامل لبيانات كل مستخدم. يدعم RTL بالكامل.

## الميزات
- تسجيل دخول / إنشاء حساب
- إدارة الواجبات (إضافة، تعديل، حذف، حالة، أولوية، موعد استحقاق)
- لوحة تحكم بإحصائيات
- تصفية وبحث وترتيب
- تصميم احترافي (RTL)

## التشغيل
افتح index.html في المتصفح. لا حاجة لخادم.
